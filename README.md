# Pokédex

An iOS Pokédex built with SwiftUI and Swift 6 structured concurrency, powered by [PokéAPI](https://pokeapi.co).

## Stack

- SwiftUI
- Swift 6 with strict concurrency checking
- async/await, actors and TaskGroup
- Swift Testing
- iOS 17+

## Getting started

The Xcode project is generated with [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml`.

```bash
brew install xcodegen
xcodegen generate
open Pokedex.xcodeproj
```
